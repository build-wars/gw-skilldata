GW Skilldata Release Files

Project home: https://github.com/build-wars/gw-skilldata

Library

The Library includes several helper methods for handling and combining the data from the different sources.

JSON Skilldata

  • Common skilldata: skilldata.json
  • Combined data including all languages: skilldata-combined.json
  • Data for individual skills can be fetched via: https://build-wars.github.io/gw-skilldata/json/skills/[SKILL_ID].json

JSON Skill Descriptions

  • Skill descriptions (German, GuildWiki): skilldesc-de-guildwiki.json
  • Skill descriptions (English, Guild Wars Wiki): skilldesc-en-gww.json

JSON Schemas

paw·ned² Databases

Please note that the files are Windows-1252 encoded.
The "en2" prefixed databases are for the english version of paw·ned².
